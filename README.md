## Quick Start

Check out https://nodered.org/docs/getting-started/ for full instructions on getting
started.


1. `npm start`
2. Open <http://localhost:3030/admin>

## Developers

If you want to run the latest code from git, here's how to get started:

1. Clone the code:

        git clone https://bitbucket.org/koreteam1/integration-service
        cd integration-service

2. Install the integration-service dependencies

        npm install

3. Build the code

        npm run build

4. Run

        npm start
